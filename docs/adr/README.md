# Architecture Decision Records

Decisions behind the UltraHonk verification work described in the [project plan](../ultrahonk.md). There is one record per decision. Each record states the context, the decision, the options considered, the trade-off, the consequences and the outcome.

> **Status (2026-11-23).** All records are accepted decisions, and all of them have been carried out. Each record has an "Outcome" section dated 2026-11-23 that says what was built and where it differs from the decision. Measured sizes and gas are in [`ultrahonk/README.md`](../../ultrahonk/README.md).

## Index

## Conventions

- Every record keeps its decision and its reasoning as they were made on 2026-11-22. Statements of fact that the code later contradicted are corrected in place.
- A ticked action item was carried out. An unticked one says why it was not.
- Upstream Solidity file and function names are references to the Barretenberg code being ported. They are not project code.
- Stage numbers refer to the stage tables in the [project plan](../ultrahonk.md#stages).
