# Architecture Decision Records

Decisions behind the UltraHonk verification work described in the [project plan](../ultrahonk.md). There is one record per decision. Each record states the context, the decision, the options considered, the trade-off and the consequences.

> **Status (2026-11-22).** All records are accepted decisions. Stage 0 was completed for the original non-ZK target; stage 0b, which switches to the ZK flavor and to the Fe-only layout, is in progress. No action item in any record is marked done. Assessments are qualitative: no measurement has been recorded yet.

## Conventions

- A value tagged **[ZK: TBC]** comes from the original non-ZK plan and is to be confirmed from the generated ZK contract (stage 0b, in progress).
- Upstream Solidity file and function names are references to the Barretenberg code being ported. They are not project code.
- Stage numbers refer to the stage tables in the [project plan](../ultrahonk.md#stages).
